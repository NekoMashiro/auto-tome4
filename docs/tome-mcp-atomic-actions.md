# 按游戏原生命令拆开的原子操作

日期：2026-11-02。依据：Steam 安装的 Tales of Maj'Eyal 1.7.6（`TalesMajEyal/game/modules/tome.team`、`game/engines/te4-1.7.6.teae`）。

游戏给玩家的按键很多，会改变世界的命令很少。热键、商店、纹身、加点、丢东西都不是各自一种新动作，而是 **先做一个命令，再回答它弹出来的界面**。下面这三层是关卡内操作的拆法。它们盖住哪些、还缺哪些入口，见 [原子操作的覆盖范围](tome-mcp-atomic-actions-coverage.md)。

## 1. 三层就够

| 层 | 做什么 | 个数 |
| --- | --- | --- |
| 世界命令 | 按一下就会走路、放技能、休息，或打开一个会改角色的窗口 | 11 |
| 回答 | 当前窗口要你点的东西。所有窗口共用这一套 | 6 |
| 只看 | 面板、任务、地图、日志。不推进回合，现有 `observe` / `inspect` / `map` 已经覆盖 | — |

方向沿用游戏小键盘：`7 8 9 / 4 6 / 1 2 3`。

### 世界命令

来源是 `data/keybinds/move.lua`、`actions.lua`、`inventory.lua`，以及 `mod/class/Game.lua` 的 `setupCommands`。

| 原子操作 | 对应游戏按键 | 游戏实际做什么 |
| --- | --- | --- |
| `step(方向)` | 移动 | 走一格。空地就移动；格子上是敌人就普攻；是门、商店、地形机关就走那格自己的逻辑。不用再拆「攻击」「对话」「进店」 |
| `wait` | 原地等待 | 耗一回合 |
| `run(方向)` | 向某方向跑 | 沿这个方向一直走，直到撞上东西、没能量或被打断 |
| `auto_explore` | 自动探索 | 原生自动探索，看见敌人等情况会自己停 |
| `rest` | 休息 | 原生休息，受伤、敌人、坏状态、对话框会打断 |
| `change_level` | 上下楼 | 只有脚底是出口才生效 |
| `use(id)` | 热键，或技能栏里点一个技能 | `id` 是技能或物品。热键只是记住了这个 id。用完之后要不要选目标、确认、说话，由这个对象自己决定 |
| `pickup` | 捡起 | 脚下只有一件就直接捡。多于一件就弹出列表，接着用「回答」去点 |
| `switch_weapons` | 切换武器组 | 主手/副手武器组对调，后面没有菜单 |
| `open_inventory` | 背包 | 打开背包+装备。点某一件后弹出物品菜单（使用、装备、卸下、丢弃……） |
| `open_levelup` | 升级窗口 | 打开升级界面。加属性、学技能、解锁类别都在这个窗口里完成 |

`use(技能)` 和 `use(物品)` 是同一个操作。持续技能再 `use` 一次就是开关。被动技能不能 `use`，只能在升级窗口里点。

### 回答

不管弹出来的是对话、确认框、背包菜单、商店还是纹身槽，都只用这些。选项用界面给的 `option_id`，不靠按钮上的文字去猜。

| 原子操作 | 游戏里长什么样 |
| --- | --- |
| `choose(选项)` | 点列表或按钮：是/否、对话分支、物品菜单、纹身槽、商店里的一行、地图菜单 |
| `aim(单位 或 坐标 或 方向)` | 技能索敌。格子、点一个能看见的单位、或八方向，三种里当前提示要哪种就答哪种 |
| `quantity(数量)` | 「丢几件」「买几件」那种数字框 |
| `adjust(节点, +1 或 -1)` | 升级窗口里对属性、技能、类别左键加一点、右键退一点。这不是普通菜单，所以单独留一个 |
| `text(文字)` | 给物品打标签、给队友改名、建角时取名 |
| `cancel` | 关掉当前这一层，等于按退出 |

一层回答完，游戏可能再弹下一层。继续用同一套回答，直到这个命令结束。认不出的窗口也先把它的按钮列出来，能对上 `choose` 就答，对不上再交给玩家。

## 2. 看起来很复杂的行为，其实是上面的组合

| 玩家想做的事 | 实际按键顺序 |
| --- | --- |
| 镶嵌或替换纹身 | `use(符文或注入)` → `choose(要替换的槽，或「花 1 点类别点买新槽」，或取消)` |
| 只扩纹身槽、先不镶 | `open_levelup` → `choose(Inscriptions)` → `choose(是)` |
| 喝药水、用注射、用装备上的充能 | `use(物品)`。有的还要再 `aim` |
| 放一个技能 | `use(技能)` → 零次或多次 `aim` / `choose` |
| 普攻 | `step(敌人所在方向)`。撞上去就会打 |
| 开门、踩机关 | `step(那个方向)` |
| 和 NPC 说话 | `step(NPC 方向)` 或走到触发格 → 反复 `choose`，直到对话结束 |
| 买东西 | `step` 进商店 → `choose(商店里的那一件)` → `quantity` → `choose(确认购买)` |
| 卖东西 | 同上，改点自己背包那一侧 |
| 捡东西 | 一件：`pickup`。一堆：`pickup` → `choose(哪一件)`，可重复 |
| 装备 | `open_inventory` → `choose(那一件)` → `choose(Wield/Wear)` |
| 卸下 | `open_inventory` → `choose(装备栏那一件)` → `choose(Take off)` |
| 丢弃 | `open_inventory` → `choose(那一件)` → `choose(Drop)` → 堆叠再 `quantity`。世界地图上还会再 `choose(销毁)` |
| 幻化 / 移回背包 | `choose(那一件)` → `choose(幻化或移回)` → 幻化再 `choose(确认)` |
| 打标签 | `choose(那一件)` → `choose(Tag)` → `text` |
| 给配件装到装备上 | `choose(配件)` → `choose(Attach)` → `choose(装到哪一件上)` |
| 鉴定（角色有自动鉴定时） | `choose(那一件)` → `choose(Identify)` |
| 把东西交给队友 | `choose(那一件)` → `choose(Transfer)` → `choose(交给谁)` |
| 加 1 点属性 | `open_levelup` → `adjust(力量等, +1)` → `choose(完成)` → `choose(接受)` |
| 学 1 点技能或提升类别 | `open_levelup` → `adjust(那个技能或类别, +1)` → 完成并接受 |
| 退回刚点的一点 | 同一个窗口里 `adjust(节点, -1)`。只能退这次窗口里点过的 |
| 学觉醒 | `open_levelup` → `choose(Prodigies)` → `choose(哪一个觉醒)` → 完成并接受。这时才真正学会 |
| 休息、自动探索、上下楼 | 单独一个命令：`rest` / `auto_explore` / `change_level`。地图菜单里的同名项也是在调它们 |
| 看地形再决定 | `look` 点一格 → `choose`。菜单里的「下楼 / 捡起 / 休息 / 背包 / 放技能」仍然落到上面的命令，不是新动作 |
| 切换控制的队友 | `choose(第几位)` |
| 给队友下指令 | `choose(这个队友的命令)` → 再按提示 `choose` / `aim` / `quantity` / `text`（行为、目标、牵引距离、改名、解散） |
| 存档、退出 | `save`、`quit`。不改变关卡，也不用回答玩法窗口 |
| 建角 | 进游戏之前的一串 `choose`（种族、职业、难度……）+ `text(名字)` + `choose(开始)`。进关之后不再用 |

物品菜单的可选项来自 `mod/dialogs/UseItemDialog.lua`：使用、装备、卸下、丢弃、鉴定、幻化、标签、转交、配件装卸。某一件物品当前没有的项不会出现。

纹身对话来自 `data/chats/player-inscription.lua`：每个已有槽是一个选项，类别点够并且加槽次数未满时多一个「买新槽」，最后是取消。

## 3. 按键很多，但不是新行为

| 游戏里看到的 | 归到哪个原子操作 |
| --- | --- |
| 热键 1–12，以及后面几页热键 | `use(这个热键绑定的技能或物品)` |
| 技能栏 `Use talents` | 列表里 `choose` 一个技能，然后同样是 `use` |
| 单独的「装备 / 卸下 / 使用 / 丢弃」快捷键 | 少弹一次背包，本质仍是 `choose(物品)` 再 `choose(菜单项)` |
| F1–F8 切换队友、Shift+F1 下指令 | `choose(队友)` / 队友指令 |
| 角色面板、任务、大地图、消息日志、传说、材料 | 只看。不进世界命令 |
| 截图、开关界面、小地图、付费商店、调试控制台 | 不是在玩这局游戏 |

## 4. 和现在 MCP 动词的对应

现在 `tome.act` 为很多玩法各做了一个动词。按游戏自己的分法，它们大多是上面某一步，或者还没接上「回答」。

| 现在的 MCP 动词 | 按游戏来看 |
| --- | --- |
| `move` | `step` |
| `attack` | `step(敌人方向)`。可以留着当明确指定目标的快捷方式 |
| `wait` / `rest` / `auto_explore` / `change_level` | 同名原子操作 |
| `use_talent`、`set_sustain` | 都是 `use(技能)` |
| `use_item` | `use(物品)` |
| `pickup` | `pickup` |
| `equip` / `unequip` | 物品菜单里的 Wear / Take off |
| `spend_stat` / `learn_talent` / `learn_category` / `unlearn_talent` | 升级窗口里的 `adjust` |
| `tome.respond` / `tome.dismiss` | 已经是 `choose` / `aim` / `cancel` 的一部分 |
| 还没有的：丢弃、买卖、纹身、觉醒、数量、升级窗口本身 | 不需要新动词。补上 `open_inventory`、`open_levelup`、`quantity`、`adjust`、`text`，并让商店、物品菜单、升级窗口、纹身对话都走 `choose` |

`run`、`switch_weapons`、`save`、`quit`、建角，游戏里有独立按键，当前 MCP 还没有对应命令。
